# くらしの道しるべ

![くらしの道しるべのトップ画面。「くらしの『どうすればいい？』は、ぜんぶここから。」の見出しと、困りごとを書く入力欄が並んでいる。](docs/images/01-top.png)

くらしの「どうすればいい？」に、東京都のオープンデータからその場で答えを返すポータル。
簡単なことはここで答え、**詳しく知りたくなったら公式サイトへご案内する。**

## 使い方

答えは公式サイトに載っている。**問題は、そこまでたどり着けないこと。**
どの区市町村の、どのページを見ればいいのか分からないまま検索して、途中で諦めてしまう。
この画面は、その最初の一歩を肩代わりする。

### 1. チャットで聞く

思いついたままの言葉で書くだけ。「アイロン台を捨てたい」「西新宿７丁目の治安が知りたい」「車椅子で入れるお店を探したい」。

### 2. 簡単なことは、その場で答える

![チャットで「アイロン台を捨てたい」と聞いた結果。立川市の答えとして「粗大ごみ」「粗大ごみ回収料金 100円」が出ており、その下に出典（立川市「ごみ分別」）、時点（2026-01-15 更新のデータ）、カバー範囲が並んでいる。](docs/images/02-chat-gomi.png)

**よくある質問はここで終わる。** 分別区分も料金も、行政が公開した値そのまま。

### 3. 詳しく知りたくなったら、公式サイトへ

答えのすぐ下に、**その話題を扱っている公式ページへのリンクが出る。**

| 知りたいこと | 案内先 |
| :--- | :--- |
| 収集日・指定袋の種類 | その自治体のごみのページ |
| 粗大ごみを申し込みたい | 粗大ごみ受付センター |
| 周辺の治安を地図で見たい | 東京都防犯ネットワーク「防犯マップ」 |
