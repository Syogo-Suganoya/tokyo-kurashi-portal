# くらしの道しるべ

![くらしの道しるべのトップ画面。「くらしの『どうすればいい？』は、ぜんぶここから。」の見出しと、困りごとを書く入力欄が並んでいる。](docs/images/01-top.png)

くらしの「どうすればいい？」に、東京都のオープンデータからその場で答えを返すポータル。
ここで答えられないことは、**できないことを書いた上で**それを扱っている公式サービスへご案内する。

都知事杯オープンデータ・ハッカソン2026 応募作品。

## できること

| 画面 | 何が分かるか | 規模 |
| :--- | :--- | :--- |
| `/gomi` ごみの分別 | 品目名を入れると、お住まいの自治体の表記のまま分別区分・注意点・粗大ごみの料金が出る | 31自治体・28,815品目 |
| `/bouhan` 町丁ごとの犯罪認知件数 | 2つ入力すると並べて比べられる。前年からの増減と、何の手口でその件数になっているかも出る | 令和7年・5,142町丁 |
| `/manabi` 学びと体験の場 | 図書館・博物館・公民館などを種別をまたいで1つの地図で探せる | 849施設・9種別 |
| `/barrierfree` 車椅子で行ける場所 | 必要な設備を選ぶと、飲食店・鉄道駅・公共施設を横断で絞り込める | 3局・6,278か所 |

## 使い方

### 1. チャットで聞く

思いついたままの言葉で書くだけ。「アイロン台を捨てたい」「西新宿７丁目の治安が知りたい」「車椅子で入れるお店を探したい」。

### 2. その場で答えが返る

![チャットで「アイロン台を捨てたい」と聞いた結果。立川市の答えとして「粗大ごみ」「粗大ごみ回収料金 100円」が出ており、その下に出典（立川市「ごみ分別」）、時点（2026-01-15 更新のデータ）、カバー範囲、そして「この画面で分からないこと」が並んでいる。](docs/images/02-chat-gomi.png)

### 3. 続きは公式サイトへ案内する

答えのすぐ下に、**必ず公式サイトへの出口がある**。

- 収集日や指定袋の種類など、この画面に無いこと → その自治体のごみのページへ
- 粗大ごみの申込み → 受付センターへ（**申込みは代行しない**）
- 未対応の区市町村や、扱っていない分野 → **なぜ答えられないのかを書いた上で**、それを扱っている公式サービスへ

**「無い」と断定しない。** 行き先が無いまま終わることはない。

### じっくり探すなら、4つの画面

分野が決まっているならチャットを通らず直接いける。`/gomi` `/bouhan` `/manabi` `/barrierfree`。

![バリアフリーの画面。「オストメイト用設備がある」にチェックを入れて絞り込んだ結果、3,557か所が見つかっている。産業労働局・福祉局・交通局の3局のデータを1つにまとめて検索している。](docs/images/03-barrierfree-map.png)

`/barrierfree` なら必要な設備を選んで、飲食店・鉄道駅・公共施設を局をまたいで絞り込める（一覧と地図の両方で見られる）。
`/bouhan` は町丁を2つ入れると並べて比べられる。
