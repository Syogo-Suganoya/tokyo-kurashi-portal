# First Stage 2分間プレゼン 読み上げ原稿 — くらしの道しるべ

---

## スライド1 — 表紙（10秒）

> くらしの道しるべです。くらしの「どうすればいい？」に、東京都のオープンデータからその場で答えを返すポータルを作りました。

## スライド2 — 課題（28秒）

> ごみの分け方は区市町村ごとに別のサイトで、引っ越すと調べ直しです。治安を数字で比べたい、車椅子で入れる店を探したい——**どれも公開されているのに、探し先がばらばら**です。バリアフリーの情報は、東京都の中だけでも**3つの局が別々に**公開していました。住民から見れば1つの困りごとなのに、横断して探せません。

- 「3つの局が別々に」で右カラムの3つのロゴを指す

## スライド3 — 解決（26秒）

> そこで、困りごとをそのままの言葉で入れると答えが返るようにしました。ごみの分別は**31自治体・2万8千品目**。町丁ごとの犯罪認知件数は**5,142町丁**、前年との増減つき。学びの場は9種別を1つの地図に。バリアフリーは3局を1つに束ねて、必要な設備で絞り込めます。

- 4つの数字を言うタイミングで、下のカードを順に指す

## スライド4 — AIは答えを書かない（26秒・ここが山場）

> 一番こだわったのはここです。**AIに答えを書かせていません**。AIがするのは、どの画面で答えるかを決めることと、入力から品目名を抜き出すことだけ。分別区分も料金も、行政が公開した値をそのまま出します。**案内するURLも、人が確認した一覧の中からしか選べません**。出典・時点・この画面でできないこと・公式への出口は、書き忘れるとコンパイルが通らないようにしてあります。

- 「AIに答えを書かせていません」の前に一拍おく
- 最後の一文で、下の「型で必須」のカードを指す

## スライド5 — データと技術（16秒）

> データは東京都オープンデータカタログと警視庁から**49本のCSV**を取り込みました。取り込みはビルド時に行い、静的なJSONにしてあります。**実行時に行政のサーバを叩きません**。壊れたデータは、利用者の画面に出る前にビルドで止まります。

- 時間が押していたら3文目以降を落として「データは東京都オープンデータカタログと警視庁から49本のCSVを取り込みました。」だけにする（-72字・約13秒短縮）

## スライド6 — まとめ（18秒）

> 答えを持っているところは自分で答え、持っていないところは**できないことを書いてから**公式へ送る。行政の情報を扱うサービスとして、そこを型で守りました。未対応の区市町村も、隠さず理由を出します。ぜひお試しください。

- 最後はデモURLを指して締める

## 言い回しの注意

| 避ける言い方 | 使う言い方 | 理由 |
| :--- | :--- | :--- |
| 「AIが答えます」 | 「AIは送り先を決めるだけです」 | この作品の主張と正反対になる |
| 「治安が良い／悪い」 | 「認知件数が多い／少ない」 | 件数は人口・昼間人口・繁華街に強く影響される。**評価語は画面にも出していない** |
| 「12のテーマを網羅」 | 「くらしの困りごと」 | 審査基準の言葉であって、住民の言葉ではない |
| 「対応していない自治体があります」（弁解） | 「対応していない理由を出します」 | 範囲外の扱いは弱点ではなく設計の一部 |

## スライドの色合い設定

配色は画面と同じ**街の案内標識**に寄せる。濃い藍を地色にし、**注意を促すところだけ琥珀**にしている。
禁止の赤ではなく琥珀にするのは、「できないこと」を禁止ではなく注記として読ませるため。

### 基本の6色

| 役割 | 色 | 見本用途 | 使いどころ |
| :--- | :--- | :--- | :--- |
| INK（地色） | `#0F1720` | 濃紺グレー | 白背景での見出し文字、濃色カードの文字 |
| AI（主色） | `#17408b` | 標識の藍 | 表紙・まとめの背景、番号バッジ、数字の強調 |
| SOFT（面） | `#E3EAF6` | ごく淡い藍 | 藍の帯の上に置くラベル、白背景のカードの塗り |
| PAPER（面） | `#EEF1F5` | ごく淡い灰青 | 白背景に置くカードの塗り |
| MUTED（本文） | `#5A6472` | 青みのグレー | 白背景の本文・出典・キャプション |
| AMBER（注意） | `#8A4409` | 琥珀 | 「この画面でできないこと」「未対応の理由」だけ |

### 分野の識別色（4本の簡易版を見分けるための色）

| 分野 | 色 |
| :--- | :--- |
| ごみの分別 | `#1F6B45` |
| 町丁ごとの犯罪認知件数 | `#17408B` |
| 学びと体験の場 | `#9A4A12` |
| 車椅子で行ける場所 | `#5F3A96` |

濃い藍の上に置くときは、明るい側（`#63B98C` / `#8FB0E8` / `#D59A63` / `#B39AE0`）に差し替える。

### 補助色

| 色 | 使いどころ |
| :--- | :--- |
| `#FBF0E2` / `#8A4409` | 注意カードの塗り／その本文 |
| `#D6DCE4` | 白背景のカードの罫線 |
| `#C7D5EE` | 藍背景の上の本文・小さめの説明文 |

### ルール

- **明暗のサンドイッチ**: 1枚目（表紙）と6枚目（まとめ）は藍、あいだの2〜5枚目は白。切り替わりで場面転換を作る
- **主色が6〜7割**: 藍系で画面の大半を占め、琥珀は1枚に1か所までに抑える。強調色を増やすと「どこが注意点か」が伝わらなくなる
- **モチーフは矢印と色帯**: 案内標識の語彙をそのまま使う。**AIは箱ではなく矢印として描く**（答えが入っている箱は行政のデータと公式サービスだけ、という図の主張がスライド4の山場になる）
- **文字色のコントラスト**: 藍背景には `SOFT` か `#C7D5EE` 以上の明るさ、白背景には `INK` か `MUTED` のみ。中間色は使わない
- **数字は等幅**: 「31自治体」「28,815品目」「5,142町丁」「6,278か所」は桁が揃うように等幅で組む

### 書式

| 要素 | 設定 |
| :--- | :--- |
| フォント | 日本語 Yu Gothic / 数字・URL は Arial（PowerPoint と macOS の両方に入っている組み合わせ） |
| スライドタイトル | 32〜34pt ボールド `INK`（表紙のみ48pt 白） |
| カード見出し | 18〜21pt ボールド |
| 本文 | 12.5〜15pt、行間はやや広め |
| 数字の callout | Arial 32〜40pt ボールド `#17408B`（濃色カード内は `SOFT`） |
| 判型 | 16:9 ワイド（13.3 × 7.5 インチ） |
