# 確実にヒットする入力値

デモ・画面キャプチャ・審査員に触ってもらうとき用。
**「適当に打っても何か返る」ようには作っていない。** 答えを持っていない品目・町丁は、
持っていないとそのまま言う。下の表はすべて**手元で実際に叩いて結果を確認済み**。

> 公開URLはまだ無いため、確認は `npm run dev`（http://localhost:3000 ）で行った。
> デプロイ後に同じ表を公開URLで通し直すこと（[DEPLOY.md](DEPLOY.md) 4章）。

## 何を入れると外れるのか

| # | 外れる条件 | 根拠 |
| ---: | :--- | :--- |
| 1 | **その自治体のCSVに載っていない品目** | 品目一覧は自治体ごとに違う。瑞穂町に「せん定枝」は無い（他市にはある） |
| 2 | **カナ・ひらがなで打つ**（8自治体を除く） | カナ列を持つのは多摩市・西東京市・東久留米市・中野区・日野市・三鷹市・荒川区・東村山市の**8自治体だけ**。他は漢字・カタカナの表記どおりに打つ |
| 3 | **粗大ごみの金額を期待する**（7自治体を除く） | 金額を持つのは立川市・板橋区・文京区・三鷹市・港区・荒川区・東村山市の**7自治体だけ**。他は「有料」「無料」という種別しか公開されていない |
| 4 | **存在しない町丁名**（`/bouhan`） | 警視庁のCSVに載っている5,142町丁だけ。「〇〇町」を作って打つと0件 |
| 5 | **飲食店にオストメイト・おむつ交換台** | 産業労働局の飲食店データには**その項目自体が無い**。条件に入れると必ず0件 |

いずれも「見つかりませんでした」＋公式への案内が返るので、**外れても壊れた表示にはならない**。
ただし限られた実演時間では避ける。

## 3つの見どころを1回ずつ見せるなら

| ねらい | 入力 |
| :--- | :--- |
| **答えは行政の値そのまま** 分別区分も注意点も料金もオープンデータの文字 | `/chat` → 「アイロン台を捨てたい」→ 立川市 → 粗大ごみ・100円 |
| **自治体差が同じ画面で見える** 同じ品目でも答えが違い、答えられないことは答えない | 続けて `/gomi` で世田谷区の「アイロン台」→ 30cm超で粗大ごみ・**金額は公式へ** |
| **範囲外を隠さない** 未対応の理由を書いた上で公式へ送る | `/gomi` で **台東区** を選ぶ → 「カタログのCSVが区のサイト側で見つからない」と理由が出る |

3つ目は返ってくる文言がこの作品の主張そのものなので、プレゼンで見せる価値がある。

> 台東区のオープンデータは、カタログに登録されているCSVが区のサイト側で見つからない状態です
> （2026-08-17 時点、新旧2本とも）。誤ったデータをお見せしないよう、対応していません。

## 注意（実演でのつまずき）

**1. モデルが地名を書き換えることがある**

`/chat` で「荻窪５丁目」と打つと、Workers AI が `荻窪三丁部` という**存在しない地名を作った**。
部分一致で荻窪の町丁に当たるため答えは返るが、意図した町丁ではない。
**チャットから町丁を引くデモは「西新宿７丁目」を使う**（漢数字への書き換えは検索側で吸収済み）。

**2. 推論に数秒かかる**

Workers AI の応答は数秒。**画面4本（`/gomi` `/bouhan` `/manabi` `/barrierfree`）は
AIを通らない**ので即座に返る。時間が押しているときは画面から見せる。

**3. 覚えている区市町村があると聞き返さない**

チャットで一度「立川市」を選ぶと端末に覚えるので、次からは聞き返しが出ない。
**聞き返しを見せたいときは、先に `/gomi` の「よく使う区市町村」の ✕ で忘れさせる**
（または別のブラウザプロファイルで開く）。

**4. 未対応は渋谷区・台東区の2区だけ**

以前は世田谷区・東村山市も未対応だったが、いずれも対応済み。
**「未対応の例」を見せるなら渋谷区か台東区**を選ぶこと。
