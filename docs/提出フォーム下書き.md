## 3. 技術詳細

**3-1. 技術選定の理由**（310文字以内 / 現在 308文字）
```
Next.js 16＋React 19＋TypeScriptで作り、OpenNextアダプタでCloudflare Workersに載せています。

AIに外部のAPIを使わず、同じCloudflare上のWorkers AIをバインディングで呼びます。
APIキーが構成から消えるため、鍵の失効や貼り忘れで当日止まる経路がありません。

オープンデータの取り込みはビルド時に行い、静的JSONにしてリポジトリへ同梱します。
実行時に行政のサーバを叩かないので公開側の障害が波及せず、壊れたデータは
利用者の画面に出る前にビルドで止まります。

地図はAPIキー不要の地理院タイル＋MapLibre GL JSです。
```

**3-2. 生成AI等の活用方法**（310文字以内 / 現在 284文字・任意）
```
サービス内でAIにさせるのは2つだけです。どのツールを呼ぶかの判定と、
入力文からの品目名・地名の抽出です。

答えの本文はツールの戻り値、つまり行政が公開した値そのもので、AIが文章を書く経路は
ありません。URLもAIは生成せず、人が確認した26件の一覧に実在するIDからしか選べません。
AIの出力は受け取り側で既知の値だけに絞り込み、知らないツール名や区分は捨てます。

AIが停止してもキーワード判定に切り替えて動き続け、どちらの経路で答えたかを毎回画面に出します。

実装とドキュメント作成にはClaude Code（Claude Opus）を使いました。
```
